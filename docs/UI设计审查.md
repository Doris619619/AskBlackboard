# AskBlackboard 侧栏设计审查

更新日期：2026-10-14。用户反馈旧版课程卡片、字号和留白过大，本轮按桌面浏览器侧栏重新设计。旧版 17／15／13px、灰底大卡片与蓝色强调规范已被本文件替代；不再将移动端排版直接套入窄桌面面板。

## 参考与设计决定

通过 agent-reach 的 Exa 搜索查看 [Sider Chat](https://sider.ai/chat) 和 [Monica](https://monica.im/) 官方页面，并实际查看 Sider 的官方侧栏示意图。采用 Sider 的轻量工具栏、白底阅读面、常驻底部输入区结构；不复制商标、付费功能或素材，也不增加本产品没有实现的入口。

视觉方向：安静的白底阅读面，单一紫色强调，紧凑但可读。内容顺序：品牌和设置、课程范围、回答和出处、输入。交互仅保留回答进入、控件状态与来源展开反馈，减少动画偏好下全部停用。

- 约56px 品牌工具栏，课程选择和刷新同排，连接状态只占一行。
- 多课程账号不再默认 GED2005；提问里的课程简称可自动切换，回答旁保留该轮实际课程、教学班和学期。
- 正文 15px / 1.85 行高，问题和输入 14px，课程及来源标题 13px，辅助信息 11–12px。主内容优先，取消巨大圆角课程卡片。
- 用户问题使用浅灰气泡，AI 回答直接排在白底；使用清晰的 AI 标签，不增加第二层回答卡片。
- 2026-10-15按用户反馈调整：截止时间用22px半粗体突出，13px原话紧随其后，44px来源按钮直接跳转；不同班组分行。不依赖AI、采集范围等实现描述不再占据答案正文。AI引用默认展开，同来源摘录仍合并；全部资料和完整正文按需展开。
- 正常高度下输入常驻底部；视口不超过 600px 高或 260px 宽时改为整页滚动，避免高倍缩放挤压正文。
- 设置、发送、停止、刷新与来源展开均至少 44px 命中区；使用原生 select、details、dialog，保留键盘和焦点反馈。

## 主题与可访问性

使用语义色变量，浅色正文 `#202124`，辅助文字 `#626770`，强调 `#5252c7`，背景白色；深色沿用暗面层次并使用 `#b6b3ff` 强调。深浅模式均单独验证，禁用按钮不作为正文对比度结论。

键盘 Enter 发送、Shift+Enter 换行、Escape 关闭设置并恢复焦点。中文输入法组字时不发送；实体输入法与屏幕阅读器仍需人工验证，不声称已完成无障碍认证。

- 真实 Edge 侧栏：正常视口382×848 CSS px，实际学校登录态、GEB课程切换和真实DeepSeek；结果见 [验收记录](验收记录.md)。
