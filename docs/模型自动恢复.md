# 模型自动恢复

遇到响应超时、网络断开、HTTP 429 或 5xx，同一次提问自动再请求一次，复用原有课程证据，不重新抓取学校资料或增加重复消息。首次请求预算60秒，恢复请求90秒；退避至少1.5秒，按 Retry-After 最多等待10秒。15秒后通过进度回调提示模型仍在响应。

鉴权失败、余额不足、请求参数错误、JSON或证据不合格不自动重试。最终失败保留原文；自动恢复不是提供商始终可用的保证。停止会取消正在请求的网络或退避，并阻止下一次请求。

实现由 `src/ai/retry.ts` 管理次数、进度和退避；`deepseek.ts` 为每次请求独立设置覆盖响应头和正文的超时。凭据和响应正文不进入日志。

验证：假时钟覆盖60/90秒预算、等待提示、取消退避、两次失败封顶、Retry-After上限和不重试的错误。浏览器在隔离网络中模拟首次503、次轮成功，断言同一轮显示答案、恰好两次模型调用、学校公告只采集一次。以上不能证明真实提供商当前稳定性。
