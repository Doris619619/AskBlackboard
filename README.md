# AskBlackboard

在 Edge 或 Chrome 侧栏提问“GED2005 的 quiz 是啥时候”或“ECE4016 作业什么时候截止”，读取当前登录账号可见的公告或作业列表，返回有原文依据的回答和可定位的来源。

## 安装

1. 使用 Edge 116+ 或 Chrome 116+，正常登录 [学校 Blackboard](https://bb.cuhk.edu.cn/)。
2. 打开 `edge://extensions` 或 `chrome://extensions`，开启开发人员模式，选择“加载解压缩的扩展”。
3. 选择 `D:\Repo\bb\dist`。ZIP 使用前先解压，选择包含 `manifest.json` 的目录。
4. 刷新已经打开的 Blackboard 标签页，让内容脚本生效。点击 AskBlackboard 按钮打开侧栏。
5. 公告 AI 问答需要在设置中填写 DeepSeek API 密钥，默认模型为 `deepseek-flash`。作业截止查询直接读取原文，无需密钥。

构建目录 `dist/`，压缩包 `artifacts/AskBlackboard-0.1.0.zip`。安装本地扩展需由使用者确认权限。

## 使用

- 问题里的课程号或已发现的课程简称优先于顶部选择。例如选着 GED2005 时问“geb 的 pre”，会自动查询当前学期唯一的 GEB 课程。大小写、编号中间空格和连字符均可识别。
- 简称对应多门课程或教学班时，请先明确选择；不会借其他课程的公告作答。未写课程时使用顶部选择；多课程账号打开时不再默认 GED2005。历史学期必须手动选择。“No Term Assigned”不作为最新学期。
- Enter 发送，Shift+Enter 换行，中文输入法确认候选词不会发送。
- 作业、report/报告、lab/实验、project/项目等截止问题（含ddl）同时核对课程公告和作业说明，无需AI。支持指定编号；Report1与Lab 1 Report作为相关名称展示并提示核对，不将代码或Report2的日期当作Report1。只写在PDF内的日期暂不支持。
- 答案先突出时间，再给原话和可点击来源。明确日期统一展示为“2026年11月17日 19:00”；缺年份、时刻或相对日期不补猜，不同班组分开列出。多来源不猜哪项最新，不同日期保留各自出处。
- 独立的报告/代码小标题会切断前一任务的截止范围；括号中的时区仍保留，条件、改期或备选日期不会被删掉后当成确定时间。
- 每个新问题重新读取对应公告或作业列表。模型重试复用该轮显示检索时间的原文。
- 截止答案的“来源：标题”直接回到公告或作业列表；AI引用原话默认展开，完整来源正文、全部资料和读取范围可按需展开。不会进入上传或提交入口。
- 公告只有日期或时长时说明未注明开始时刻；Quiz 2 无依据时不借 Quiz 1 日期。next Thursday 等相对时间保留为“该公告所说的下周四”，不按提问当天猜日历日期。
- 模型超时、断网、限速或服务暂不可用会自动恢复一次：首次最多60秒，第二次最多90秒，退避1.5～10秒；15秒后显示等待进度，可随时停止请求和后续重试。鉴权、余额或无效引用不盲目重试；最终失败仍保留原文。
- 登录失效时在学校页面重新登录，再刷新课程或重试读取。
- 设置支持跟随系统、浅色、深色；关闭设置恢复键盘焦点。白底紧凑侧栏，截止时间22px、原话13px；主要操作至少44px；高倍缩放或短侧栏使用整页滚动，保证正文可读。

支持公告与课程内容列表中的作业说明；不读取 PDF、附件正文、测验作答或作业提交页，不提供日历、提醒和后台同步。作业最多遍历40个安全页面，约60秒预算（进行中的单页读取有独立超时）；无法读全时明确显示资料不完整。

## 数据与权限

仅申请 `storage`、`sidePanel` 及 Blackboard、DeepSeek 两个域名。学校密码与 Cookie 留在浏览器。密钥存于扩展受信的 `chrome.storage.local`，不发给学校页面、不随安装包分发。

目前使用窗口级侧栏，同一窗口切换标签页时侧栏可能继续显示。界面的显示作用域与数据读取权限不同：学校内容脚本只注入Blackboard，并不因此读取其他网站。改为仅Blackboard标签页显示需要调整Side Panel的tabId级配置。

密钥没有内置在代码里。不同浏览器配置文件各自保存密钥和学校登录状态；独立验收窗口需要使用者自行登录并配置。

公告 AI 问答会将问题和所选课程公告正文发送给 DeepSeek；作业截止查询在本地提取，不发送模型。来源链接由程序生成，引用必须属于本轮原文。会话与资料只保留在当前侧栏内存中，不建立历史数据库。

## 开发

Node.js 22.12+ 与 npm：

```powershell
Set-Location D:\Repo\bb
npm ci
npm run check
npm run package
```

`npm run dev` 提供空状态界面预览，不连接学校、不存密钥、不生成示例答案。实际功能需加载扩展。改源码后重新构建，在扩展管理页重新加载并刷新学校页面。

本地构建后，侧栏可能已经读取新文件，但Edge仍运行旧后台。侧栏刷新课程按钮、刷新学校网页、关闭再打开侧栏，都不等于重新加载扩展。请在 `edge://extensions` 的 AskBlackboard 卡片点击“重新加载”，再刷新学校页面、重新打开侧栏。密钥保留。新版会检查后台协议，不一致时明确提示并提供“重新加载插件”按钮；按钮会关闭侧栏，需要重新打开。

浏览器回归会加载实际扩展，但学校和模型响应使用虚构数据，不能代替真实账号验收：

```powershell
npx playwright install chromium
npm run test:browser
# 使用本机 Edge 时，可指定其实际安装路径：
$env:BB_BROWSER_EXECUTABLE = 'C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe'
npm run test:browser
```

`node scripts/runtime-upgrade-smoke.mjs` 使用隔离配置模拟旧后台配新界面，再点击真正的扩展重新加载按钮，验证配置保留及作业查询恢复；学校与模型依然使用虚构网络。

测试使用独立 `.local/browser-smoke-*` 配置，不继承日常浏览器凭据；启用离线网络并由测试路由返回虚构资料。报告和截图位于 `artifacts/browser-smoke/`。学校、真实模型和真正侧栏的最新验收结果见 [验收记录](docs/验收记录.md#2026-10-14-edge-真实验收)。

| 目录 | 职责 |
| --- | --- |
| `src/blackboard/` | 课程发现、安全地址、DOM 解析、分页及定位 |
| `src/extension/` | 后台协调与内容脚本入口 |
| `src/ai/` | 模型请求、提示词及证据校验 |
| `src/shared/` | 类型、受信设置、错误和消息客户端 |
| `src/ui/` | 侧栏、会话、出处及设置 |
| `tests/` | 虚构样本解析、依据和错误恢复测试 |
| `scripts/` | 构建与打包 |

`public/manifest.json` 定义权限与入口，`package.json` 定义命令，`tsconfig.json` 定义类型检查；`package-lock.json` 为自动依赖锁文件，不手工插入 JSON 注释。
